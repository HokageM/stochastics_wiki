# CLAUDE.md — Stochastics Wiki Schema

This repository is an **LLM-maintained personal wiki** for the *Stochastics* module at
**TUHH (Technische Universität Hamburg)**.

**You (the LLM) own the `wiki/` layer entirely.** You write it, update it, cross-reference it,
and keep it consistent. The human owns `raw/` (sourcing) and asks the questions.

---

## 1. Language & content rules

- **Everything in the wiki is written in English**, even when the source notes are in German.
  Keep the German term in parentheses on first use when it is a standard course term,
  e.g. "law of total probability (*Satz von der totalen Wahrscheinlichkeit*)".
- **Mermaid diagrams wherever a structure, decision, or relationship can be drawn.**
  Decision trees for "which test/distribution do I use?", flowcharts for proof structure,
  graphs for Markov chains, mindmaps for topic maps.
- **Pseudocode wherever a procedure exists** (hypothesis tests, estimators, simulation
  algorithms, combinatorial counting recipes). Use fenced ```text blocks with numbered,
  imperative steps — language-agnostic, not Python.
- **Math in LaTeX**: inline `$...$`, display `$$...$$`. Always define every symbol used.
- Never invent content that is not in the sources. If a handwritten page is unreadable,
  write `> ⚠️ Unreadable in source: <page ref>` instead of guessing.

## 2. Directory structure

```
raw/                      # IMMUTABLE. Never edit or delete anything here.
  *.pdf                   # Scanned handwritten lecture notes, exercises, formula sheet
  pages/<pdf-stem>/       # Rendered page images (png) generated for vision reading
wiki/                     # LLM-owned. Everything here is generated by you.
  index.md                # Content catalog — every page, one line each
  log.md                  # Append-only chronological record
  overview.md             # The course map: what the module covers, how it hangs together
  open-questions.md       # Things unresolved, contradictory, or unreadable in the sources
  cheatsheet.md           # Condensed exam formula sheet, derived from the formula summary
  sources/                # One page per ingested source (or per lecture block)
  concepts/               # Definitions & ideas (sigma-algebra, independence, convergence...)
  theorems/               # Named results with statement, assumptions, proof sketch, use
  distributions/          # One page per distribution
  methods/                # Procedures: estimators, tests, confidence intervals, simulation
  exercises/              # Worked exercise/tutorial problems, grouped by topic
tools/
  render_pages.py         # PDF -> page images (pymupdf); see §3
CLAUDE.md                 # This schema
```

File naming: `kebab-case.md`, singular, descriptive.
Examples: `concepts/conditional-probability.md`, `theorems/central-limit-theorem.md`,
`distributions/poisson.md`, `methods/maximum-likelihood-estimation.md`.

## 3. Reading the raw sources (handwritten scans)

The sources are **scanned handwritten pages inside large PDFs**. You cannot read them as text.
Workflow:

1. Convert the PDF (or just the page range you need) to grayscale 150-DPI images once:
   ```text
   py tools/render_pages.py raw/<name>.pdf            # all pages
   py tools/render_pages.py raw/<name>.pdf 1 40       # pages 1-40, 1-based inclusive
   -> raw/pages/<name>/page-001.png, page-002.png, ...
   ```
   Already-rendered pages are skipped. Use `py` (not `python`) on this machine.
   The PDFs are large (20-70 MB); render in chunks of ~40 pages rather than all at once.
2. **View the images in batches of 3–5 pages**, in order. Never skip pages.
3. Transcribe as you go: definitions, theorems, formulas, worked examples, exercise numbers.
4. Record the page range you covered so an interrupted ingest can resume.

`raw/pages/` is generated, not a source of truth — it may be gitignored.

## 4. Page formats

Every wiki page starts with YAML frontmatter:

```yaml
---
title: Central Limit Theorem
type: theorem          # source | concept | theorem | distribution | method | exercise | meta
tags: [convergence, limit-theorems, exam-relevant]
sources: ["stochastics_6_7.pdf p.12-15"]
updated: 2026-10-15
---
```

Then `[[wiki-links]]` in Obsidian style for every cross-reference — use them liberally,
every mentioned concept that has (or should have) a page gets linked.

### `concepts/`
```
# <Name> (<German term>)
> One-sentence plain-English definition.
## Formal definition      (LaTeX, all symbols defined)
## Intuition              (what it actually means; a Mermaid diagram if drawable)
## Relation to other ideas ([[links]], and how they differ)
## Pitfalls               (what the lecture/tutorial warned about)
## Appears in             ([[sources]], [[exercises]])
```

### `theorems/`
```
# <Name>
## Statement              (LaTeX)
## Assumptions            (bullet list — be strict, these are exam traps)
## Proof sketch           (steps; Mermaid flowchart if the proof has structure)
## When to use it         (recognition cues)
## Worked example
## See also
```

### `distributions/`
Table-first page: support, PMF/PDF, CDF, $E[X]$, $\mathrm{Var}(X)$, MGF, parameters.
Then: story/when it arises, relationships to other distributions (Mermaid graph:
limits, sums, conjugates, special cases), typical exercise patterns.

### `methods/`
```
# <Method>
## Goal / when to use
## Assumptions
## Procedure              (pseudocode block — mandatory)
## Decision diagram       (Mermaid, if there are branches)
## Worked example
## Common mistakes
```

### `exercises/`
One page per tutorial sheet or coherent problem group:
problem restatement → which [[concepts]]/[[theorems]] it uses → solution steps →
the generalizable takeaway ("this is the pattern for ...").

### `sources/`
One page per ingested lecture block: what it covered, page range, key takeaways,
and a list of every wiki page created or updated from it.

## 5. Operations

### Ingest
1. Render pages (§3) and read them in order.
2. **Discuss the key takeaways with the user before writing**, unless told to batch-ingest.
3. Create `wiki/sources/<name>.md`.
4. Create/update the downstream pages: concepts, theorems, distributions, methods, exercises.
   A single lecture block typically touches 8–15 pages. Prefer *updating* an existing page
   over creating a near-duplicate.
5. Update `wiki/index.md` and `wiki/overview.md`.
6. Add anything ambiguous/unreadable to `wiki/open-questions.md`.
7. Append a `log.md` entry.

### Query
Read `index.md` first → open the relevant pages → answer **with citations to wiki pages and
raw page numbers**. If the answer is non-trivial and reusable (a comparison, a derivation,
an exam-style walkthrough), **file it back into the wiki** as a new page, link it, index it,
and log it. Do not let good synthesis die in chat history.

### Lint
On request, health-check the wiki and report:
- contradictions between pages (notation drift is the most likely one here)
- concepts referenced but having no page; orphan pages with no inbound links
- missing Mermaid diagram / pseudocode where the format demands one
- undefined symbols; inconsistent notation ($P$ vs $\mathbb{P}$ — **use $\mathbb{P}$**)
- stale `updated` dates and index entries that no longer match reality
- gaps in coverage vs. `overview.md`, and good next questions to ask

## 6. Notation conventions (keep these consistent everywhere)

| Meaning | Symbol |
|---|---|
| Probability measure | $\mathbb{P}$ |
| Expectation / Variance | $\mathbb{E}[X]$ / $\mathrm{Var}(X)$ |
| Sample space / event / sigma-algebra | $\Omega$ / $A$ / $\mathcal{F}$ |
| Distributed as | $X \sim \mathcal{N}(\mu, \sigma^2)$ |
| Estimator | $\hat{\theta}$ |
| Sample mean | $\bar{X}_n$ |
| Convergence | $\xrightarrow{d}$, $\xrightarrow{P}$, $\xrightarrow{a.s.}$ |

If a source uses different notation, use the table above in the wiki and note the source's
variant once on the relevant page.

## 7. log.md format

Append-only, newest at the bottom, one block per operation:

```markdown
## [2026-10-15] ingest | stochastics_1_2.pdf p.1-40
- Read: pages 1-40 (lecture blocks 1-2)
- Created: concepts/sample-space.md, concepts/sigma-algebra.md, distributions/binomial.md
- Updated: index.md, overview.md
- Open questions: 2 (see open-questions.md)
```

Prefix is fixed so `grep "^## \[" wiki/log.md | tail -5` works.
Operation keywords: `ingest`, `query`, `lint`, `refactor`.

---

## 8. Hard rules

1. Never modify anything in `raw/` except writing into `raw/pages/`.
2. Never write a wiki page without frontmatter and at least one `[[link]]`.
3. Never finish an ingest without updating `index.md` and appending to `log.md`.
4. Never guess at unreadable handwriting — flag it.
5. Everything in English; Mermaid and pseudocode wherever they apply.
